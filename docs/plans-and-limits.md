# Plans and limits

What counts against a monthly allowance, what never does, when the month resets, and what
happens when you run out:

**[whatproblem.dev/plans-and-limits](https://whatproblem.dev/plans-and-limits)**

That page is maintained; this file is a pointer so the two cannot drift.

The short version: **one issue costs one**, however many rounds of conversation it takes.
Follow-up replies, the closing summary, the install introduction, and picking an issue up
again are never charged.

Questions about how the allowance works in general belong on
[the tracker](https://github.com/williamsinitiativesltd/whatproblem/issues/new?template=question.yml).
Questions about **your** allowance go to [support@whatproblem.dev](mailto:support@whatproblem.dev),
so your account details stay off a public thread.
