# How it works

What the bot does when an issue is opened, how far a conversation goes, what the clarity
score means, and everything it leaves alone:

**[whatproblem.dev/using-the-bot](https://whatproblem.dev/using-the-bot)**

That page is maintained; this file is a pointer so the two cannot drift. The copy that
used to live here had gone wrong twice: it described a conversation that closes itself
after 24 hours of quiet, when in fact nothing happens at the 24 hour mark and the next
comment on the issue is what checks, and it said the bot-skip note appears the first time
a bot files an issue, when it appears at most once a month per repository.

If the bot did not respond at all, that is [troubleshooting](troubleshooting.md), which
lives here rather than on the site so the tracker is one click away.
